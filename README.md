# TodoLock

일반 할 일(todo) 앱 + **잠금해제하면 오늘의 할 일이 자동으로 뜨는** 기능.
오늘 남은 할 일이 없으면 아무것도 뜨지 않습니다.

---

## 소개

할 일 앱을 깔아놓고 **정작 앱을 열지 않아서** 할 일을 잊는 문제를 해결하려고 만든
안드로이드 앱입니다.

> 사람은 하루에 수십 번 휴대폰 잠금을 해제합니다.
> 그 순간이 이미 화면을 보고 있는 유일하게 확실한 시점이므로,
> **할 일을 보러 가는 대신 할 일이 찾아오게** 만들었습니다.

잠금을 해제하면 오늘 남은 할 일이 화면 위에 바로 떠서, 훑어보고 닫으면 됩니다.
오늘 할 일이 없거나 이미 다 끝냈으면 아무것도 뜨지 않아서 방해가 되지 않습니다.

**이런 사람에게 맞습니다** — 알림은 무시하게 되지만 잠금해제 순간의 강제 노출은
효과가 있는 분, 서버 계정 없이 폰 안에만 데이터를 두고 싶은 분.

## 주요 기능

| 기능 | 설명                                                                                        |
|---|-------------------------------------------------------------------------------------------|
| 잠금해제 시 자동 표시 | 잠금을 푼 직후 오늘의 할 일 팝업이 뜹니다                                                                  |
| 조용한 기본 동작 | 오늘 남은 할 일이 없으면 표시 안 함. 팝업에는 완료된 항목을 보여주지 않습니다                                             |
| 표시 빈도 3단계 | 매번 / 1시간마다 / 하루 1번 — 잠금해제가 잦아도 피곤하지 않게 ([3번 항목](#3-표시-빈도-설정))                             |
| 기한 설정 | `오늘` / `내일 (요일)` / `날짜 선택` → 날짜 선택은 달력. 고르지 않으면 오늘                                        |
| 미리 알림 | `내일 (요일) 9시` / `다음 주 (요일) 9시` / `날짜 및 시간 선택` → 달력 다음 시계. 기한과 무관한 절대 시각으로 저장됩니다            |
| 알림 방식 3단계 | `알림창`(알림창만) / `헤드업`(알림창 + 화면 위에 잠깐) / `전체 팝업`(알림창 + 팝업) |
| 알림에서 바로 완료 | 알림의 `완료` 버튼으로 앱을 열지 않고 처리. 기기가 꺼져 있어 놓친 알림은 12시간 안이면 켠 뒤에 알려줍니다 |
| 중요 표시 · 정렬 | ★ 를 켜면 같은 날짜 안에서 위로. 정렬은 날짜(오래된 것 먼저) → 중요 → 미리 알림 이른 순 |
| 목록에서 바로 | 행을 누르면 수정, 체크박스로 완료, ✕ 로 삭제 |
| 홈 화면 위젯 | 목록을 홈에서 보고 그 자리에서 완료(`○`) · 수정 · 중요(`☆`) · 추가(`＋`). 앱이 열리지 않습니다 |
| 위젯 설정 | 톱니바퀴에서 불투명도(20~100%)와 글꼴 크기(작게·보통·크게)를 조절                                                 |

## 기술 스택

- **Kotlin** + Android View 시스템 (ViewBinding), Material Components
- **minSdk 24 / targetSdk 34** — Android 7.0 이상, 제조사 무관
- Java 17 (명령줄 빌드 시 `JAVA_HOME` 을 JDK 17 로 지정해야 합니다 —
  스튜디오 번들 JDK 는 버전이 높아 이 프로젝트의 Gradle 8.7 이 처리하지 못하고
  `25.0.2` 같은 오류로 실패합니다. 스튜디오 안에서 빌드할 때는 문제없습니다)
- 저장소는 **SharedPreferences + JSON** — Room·애노테이션 프로세서 없음
- 외부 라이브러리는 AndroidX / Material 뿐, **네트워크 코드 없음**
- **GitHub Actions** 에서 푸시마다 빌드를 검증합니다

## 개인정보

`INTERNET` 권한이 없습니다. 할 일 데이터는 기기 내부 SharedPreferences에만 저장되며
어디에도 전송되지 않고, 계정·로그인·분석 도구도 없습니다.

## 1. 설치 후 필수 설정 ⚠️

**설치만 하면 잠금해제 팝업은 뜨지 않습니다.** 아래 두 개는 사용자가 직접 허용해야 하고,
안드로이드가 앱에 대신 켜주는 것을 허용하지 않는 항목입니다.

앱을 열고 우측 상단 **⚙** 를 누르면 `권한 · 도구` 카드에 필요한 버튼이 모두 있습니다.

| 항목 | 어디서 | 없으면 |
|---|---|---|
| **다른 앱 위에 표시** | ⚙ → `권한 주기` | 팝업이 뜨지 못하고 **알림으로만** 표시됩니다 |
| **배터리 최적화 예외** | ⚙ → `배터리 예외` | 절전 기능이 감지 서비스를 죽여 **팝업이 아예 안 뜨는 날**이 생깁니다 |
| 알림 권한 | 첫 실행 시 자동 요청 | 미리 알림과 대체 알림이 오지 않습니다 |
| 알람 및 리마인더 | ⚙ → `앱 정보 열기` → 알람 및 리마인더 | 미리 알림이 **몇 분 늦게** 울립니다 (Android 12+) |

허용 여부는 버튼 라벨로 확인할 수 있습니다 — 허용되면 `다른 앱 위에 표시 · 허용됨`,
`배터리 예외 · 완료` 로 바뀝니다.

### 삼성(One UI) 을 쓰신다면 하나 더

삼성은 안드로이드 표준보다 절전이 공격적이라, **포그라운드 서비스도 재우거나 종료합니다.**
그러면 잠금해제 시점에 감지가 조용히 멈춥니다.

- ⚙ → **`앱 정보 열기`** → **배터리** → **제한 없음**

최근 One UI 는 위의 `배터리 예외` 를 허용하면 이 값도 함께 `제한 없음` 이 되는 경우가 많습니다.
들어가서 이미 `제한 없음` 이면 그냥 나오시면 됩니다.

여전히 불안하면 아래도 확인하세요 (One UI 버전에 따라 메뉴가 없을 수 있습니다).

- 설정 → 배터리 → 기타 배터리 설정 → **사용하지 않는 앱을 절전 상태로 전환** 끄기
- 설정 → 배터리 → 백그라운드 사용 제한 → **절전 모드로 전환하지 않는 앱** → `+` 로 TodoLock 추가

> 삼성 전용 화면들은 공개 인텐트가 없어 앱이 직접 열 수 없습니다.
> 그래서 `앱 정보 열기` 로 앱 정보 화면까지만 데려다주고, 거기서 한 번 더 누르는 방식입니다.

## 1-1. 팝업이 안 뜰 때

| 증상 | 원인과 해결 |
|---|---|
| 팝업 대신 알림으로 뜬다 | `다른 앱 위에 표시` 권한이 없습니다. ⚙ → `권한 주기` |
| 며칠은 잘 되다가 안 된다 | 절전이 서비스를 죽인 것입니다. ⚙ → `배터리 예외`, 삼성이면 `제한 없음` 까지 |
| 아무것도 안 뜬다 | 오늘 **남은** 할 일이 없으면 표시하지 않습니다. 완료된 항목만 있으면 뜨지 않습니다 |
| 하루에 한 번만 뜬다 | ⚙ → `표시 빈도` 가 `하루 1번` 입니다. `매번` 으로 바꾸세요 |
| 잘 뜨는지 미리 보고 싶다 | ⚙ → `팝업 미리보기` |

앱을 열 때마다 서비스가 죽어 있으면 스스로 다시 시작하고, 워치독이 15분마다 되살립니다.
그래서 위 설정이 어렵다면 하루 한 번 앱을 열어주는 것으로도 대체로 동작합니다.

## 2. 동작 방식

```
잠금해제
   ├─ ACTION_USER_PRESENT ───────────┐  (정석 경로)
   └─ ACTION_SCREEN_ON → 키가드 감시 ─┤  (USER_PRESENT 가 안 오는 기기 대비)
                                      ↓
UnlockService (포그라운드 서비스, 알림 중요도 MIN → 상태바에 거의 안 보임)
  └─ UnlockReceiver 가 런타임 등록되어 브로드캐스트 수신
                                      ↓
오늘 날짜에 '미완료' 할 일이 있는가?
   ├─ 없음 → 아무것도 안 함
   └─ 있음 → 0.5초 후 TodayPopupActivity 표시
              (overlay 권한 없으면 → 전체화면 인텐트 알림)

Watchdog (AlarmManager, 15분 간격) ─→ 서비스가 죽어 있으면 다시 세움
```

- Android 8+ 부터 `ACTION_USER_PRESENT` 는 매니페스트로 받을 수 없어서,
  포그라운드 서비스가 **런타임에** 리시버를 등록하는 구조입니다.
- 그래서 **서비스가 죽으면 리시버도 함께 사라집니다.** 삼성 등에서 화면이 꺼진 동안
  앱이 재워지면 잠금해제를 놓치게 되므로, `Watchdog` 이 알람으로 프로세스를 깨워
  서비스를 되살립니다. 알람은 앱이 죽어도 시스템에 남아 있어 유일하게 신뢰할 수 있는 경로입니다.
  (권한이 필요한 정확 알람 대신 `setAndAllowWhileIdle` 을 매번 재예약하므로 수 분 오차가 있습니다)
- 재부팅/앱 업데이트 후에는 `BootReceiver` 가 서비스와 알람을 다시 세웁니다.

### 미리 알림

잠금해제 감지와 **완전히 별개**입니다. `AlarmManager` 가 시각이 되면 매니페스트에
등록된 `ReminderReceiver` 를 직접 깨우므로, 앱이 종료돼 있어도 울립니다.
(그래서 잠금해제 스위치를 꺼도 미리 알림은 그대로 동작합니다)

- 알람은 **재부팅과 앱 교체로 사라집니다.** `BootReceiver` 와 앱 진입 시 다시 세웁니다.
- 그 사이에 시각이 지나버리면 알림이 영구히 유실되므로, 복구 시점에 **12시간 이내로
  놓친 알림은 지금이라도 띄웁니다.** 중복 방지를 위해 `Todo.notified` 로 표시하고,
  알림 시각을 새로 정하면 이 표시를 초기화합니다.
- 알림 방식은 채널로 갈립니다. 채널 중요도는 한 번 만들어지면 코드로 바꿀 수 없어
  (생성 후엔 사용자 소유), 헤드업 없는 모드를 위해 중요도가 다른 별도 채널을 둡니다.

### 위젯

`RemoteViewsService` 가 목록 행을 공급합니다. 갱신은 `TodoStore.save()` **한 곳**에
걸어서, 앱·알림·위젯 어디서 바꿔도 위젯이 따라옵니다.

- 재부팅·앱 교체 후 위젯은 `initialLayout`(빈 목록) 으로 되돌아가므로
  `BootReceiver` 와 앱 진입에서 다시 그립니다.
- 컬렉션 위젯은 행마다 `PendingIntent` 를 만들 수 없어 템플릿 하나를 공유합니다.
  어느 영역을 눌렀는지(완료 / 수정 / 중요)는 `fillInIntent` 의 extra 로 구분합니다.
- `RemoteViews` 는 `CheckBox` 를 지원하지 않아 완료 표시를 동그라미 `ImageView` 로 두고,
  앱 테마를 물려받지 못하므로 `widget_*` 색을 따로 정의합니다(다크 모드는 `values-night`).

## 3. 표시 빈도 설정

잠금해제는 하루에 수십 번 하게 되므로 세 가지 모드를 넣었습니다.
- **매번** — 잠금해제할 때마다 (원래 요구사항)
- **1시간마다** — 마지막 표시 후 1시간 지났을 때만
- **하루 1번** — 그날 첫 잠금해제에만

## 4. 파일 구조

```
app/src/main/java/com/example/todolock/
├── MainActivity.kt          할 일 목록 (완료 · 중요 · 수정 · 삭제), 추가 시트 호출, 권한 경고
├── SettingsActivity.kt      설정 화면 (잠금해제 팝업 / 미리 알림 방식 / 권한 · 도구)
├── Permissions.kt           권한 상태 판정 한 곳 — 목록과 설정이 같은 기준을 씁니다
├── AddTodoSheet.kt          기한 · 미리 알림 · 중요를 고르는 추가/수정 시트 (BottomSheetDialog)
├── QuickAddActivity.kt      위젯에서 앱을 열지 않고 추가·수정하는 투명 액티비티
├── TodoWidget.kt            홈 화면 위젯 (AppWidgetProvider)
├── TodoWidgetService.kt     위젯 목록 행 공급 (RemoteViewsService)
├── WidgetConfig.kt          위젯 불투명도 · 글꼴 크기 설정
├── WidgetSettingsActivity.kt 톱니바퀴로 열리는 위젯 설정
├── MaxHeightScrollView.kt   팝업 목록의 높이 상한 (버튼이 잘리지 않게)
├── ReminderPopupActivity.kt 알림 방식이 '전체 팝업' 일 때 뜨는 창
├── TodayPopupActivity.kt    잠금해제 시 뜨는 팝업
├── UnlockService.kt         잠금해제 감지용 포그라운드 서비스
├── UnlockReceiver.kt        ACTION_USER_PRESENT 처리 + 팝업 실행
├── BootReceiver.kt          재부팅 후 서비스 복구 + 미리 알림 재예약
├── Watchdog.kt              알람으로 프로세스를 깨워 서비스 부활 (절전 대응)
├── Reminders.kt             미리 알림 알람 예약/취소/재예약 (AlarmManager)
├── ReminderReceiver.kt      알림 발생 + 알림의 '완료' 버튼 처리
├── Notifications.kt         알림 채널 / 대체 알림 / 미리 알림
├── TodoStore.kt             SharedPreferences + JSON 저장소, 기한 계산, 정렬, 설정값
├── TodoAdapter.kt           '할 일 / 완료' 섹션 헤더 + 행 (뷰 타입 2종)
├── TodoRow.kt / Todo.kt
```

데이터는 SharedPreferences에 JSON으로 저장합니다 (Room·애노테이션 프로세서 없음 → 빌드가 단순하고 빠릅니다).

## 5. 커스터마이즈 힌트

- 팝업 지연 시간: `UnlockReceiver.kt` 의 `postDelayed(..., 500L)`
- 패키지명/앱 이름 변경: `app/build.gradle.kts` 의 `applicationId`,
  `res/values/strings.xml` 의 `app_name`
- 팝업 디자인: `res/layout/activity_popup.xml` (팝업의 할 일 한 줄은 `res/layout/item_popup_row.xml`)
- 색: `res/values/colors.xml` (다크 모드는 `res/values-night/colors.xml` 도 같이)
